# WSC1 Windows 11 Compatibility

PC版初代『鋼鉄の咆哮』をWindows 11で動かすための、非公式互換パッケージです。配布版は **v1.0.3** です。

DirectDrawの描画変換には未改変のdxwrapper v1.8.8600.25を使います。ゲーム本体、セーブデータ、音源、CDイメージは含みません。ゲームの `BCS.exe`、`BCS.ICD`、セーブファイルをディスク上で書き換えず、専用DLLはログファイルを作成しません。

## ダウンロードと導入

1. [GitHub Releasesからv1.0.3の配布ZIPをダウンロード](https://github.com/mrky05321/wsc1-win11-compat/releases/download/v1.0.3/wsc1-win11-compat-v1.0.3.zip)して展開します。SHA-256はReleaseページに記載しています。
2. ZIP内の `ddraw.dll`、`dxwrapper.dll`、`dxwrapper.ini` の3ファイルを、`BCS.exe` と同じフォルダーにコピーします。既に同名のファイルがある場合は、先にバックアップしてください。
3. `BCS.exe` を起動します。初期設定は枠付きウィンドウです。

ZIP内の `README.txt` はライセンスと導入手順をまとめたファイルです。ゲームフォルダーへのコピーは不要です。

v1.0.1またはv1.0.2から更新する場合は、`ddraw.dll` だけを交換してください。既存の `dxwrapper.ini` を残すことで、表示設定を維持できます。

Program Files内へのコピーには、Windowsの管理者許可が必要な場合があります。ゲームの起動に管理者権限は必要ありません。

## 対応する修正

- DirectDraw描画をWindows 11向けに変換します。
- ゲーム内の小窓の位置と親子関係を補正します。
- CD音声の再生経路を補助します。
- ウィンドウモードでタイトルバーによる移動とAlt+F4終了に対応します。
- ウィンドウモードの戦闘中に、マウスの兵装クリック判定と専用カーソル画像の位置を補正します。
- 専用DLLと同梱設定の描画backendは、通常の起動時にログを作成しません。

ウィンドウモードでは自動保存されません。終了前に必要なデータをゲーム内で保存してください。モーダル小窓を表示中は、先にその小窓を閉じてください。起動中のAlt+Enterによる表示切替には対応していません。

## BGM

ゲームのBGMはCD音声です。音源ファイルがない場合は、CDドライブから再生する経路を使います。ドライブを指定できない場合は、ボリューム名 `Kurogane` のドライブを選びます。固定のイメージファイルパスは参照しません。

所有ディスクから用意した `music/cd-audio.wav` と `music/cd-audio.ini` がゲームフォルダーにある場合は、そのファイル音源を再生します。確認環境ではファイル音源の再生と曲切替を確認しています。**CDドライブから直接再生したときの実際の出音は未確認です。** 音源やCDイメージは配布していません。

CUEから音源を準備する開発用ツールは `tools/extract_cd_audio.py` です。Python 3.8以上で次のように実行します。

```powershell
python tools/extract_cd_audio.py <所有ディスクのcue> <ゲームフォルダー>/music
```

対応形式は、単一IMGを使う16トラックのCUEです。

## 表示モード

ゲームを終了し、`dxwrapper.ini` の `[d3d9]` の値を変更してから起動し直してください。

| 表示モード | EnableWindowMode | WindowModeBorder | FullscreenWindowMode |
|---|---:|---:|---:|
| 枠付きウィンドウ（初期設定） | 1 | 1 | 0 |
| 枠なしウィンドウ | 1 | 0 | 0 |
| ボーダレス全画面 | 0 | 0 | 1 |
| ゲーム標準 | 0 | 0 | 0 |

## 既知の事象と確認範囲

### ウィンドウの周囲が点滅することがある

環境や実行時の状態によって、画面に変化があった際に、ゲーム外のデスクトップや他のウィンドウが点滅する場合があります。枠付き・枠なしの両方で報告されていますが、毎回発生するわけではありません。原因と発生条件は未特定で、v1.0.3では修正していません。

### 戦闘中に左下のマップ表示が黒くなることがある

ゲームを非アクティブにした後などに、左下のマップ内部が黒くなる事象が報告されています。画面写真で発生は確認しましたが、複製環境では再現できず、原因と復旧方法は分かっていません。互換DLLで修正したものではありません。再発した場合、可能ならゲームを閉じる前に画面を保存してください。

上の戦闘領域が黒く見える現象は、索敵範囲外を見ているときに起きるゲーム本来の表示です。マップ表示の黒化とは別の現象です。

### 動作確認の範囲

Windows 11の複製環境で、タイトル・準備画面、小窓の表示と操作、ファイル音源のBGM、ウィンドウ移動、Alt+F4、A-01戦闘での照準カーソル・兵装欄クリック・射撃を確認しました。全ミッション、すべての艦種・兵装、複数モニター、拡大表示での動作を保証するものではありません。

## 更新と削除

更新時はセーブ、`Gnt.ini`、`music` フォルダーを残してください。既存の表示設定を維持する場合、配布ZIPの `dxwrapper.ini` で手元の設定を丸ごと上書きしないでください。

元に戻す場合は、導入時にバックアップしたファイルを戻すか、追加した `ddraw.dll`、`dxwrapper.dll`、`dxwrapper.ini` だけを削除します。セーブやゲーム本体は削除しないでください。

## 任意の互換設定

通常は追加設定なしで使えます。個別に補正を止めたい場合だけ、`BCS.exe` と同じフォルダーに `wsc1-compat.ini` を作成します。省略した項目は有効（`1`）です。

```ini
[Compatibility]
FixPopupCoordinates=1
DigitalCDAudio=1
FixWindowMove=1
FixAltF4=1
FixBattleMouse=1
```

補正を止める項目は `0` にします。`DigitalCDAudio=0` はWAV音源への切替を止めて元のCD音声経路を使います。`FixBattleMouse=0` はウィンドウモードの兵装クリック補正と専用カーソル画像補正の両方を止めます。診断ログを有効にする設定はありません。

## ソースからビルド

Windows、Visual Studio 2022 C++ Build Tools、Windows SDK、CMake、Python 3.8以上が必要です。ゲームに合わせてWin32/x86でビルドします。

```powershell
# 専用DLLのみをビルド
.\build.ps1 -BuildOnly

# 固定版dxwrapper archiveから配布ZIPを作成
.\build.ps1 -BackendArchive 'C:\Downloads\dxwrapper.zip'
```

backendは[dxwrapper公式リポジトリ](https://github.com/elishacloud/dxwrapper)のv1.8.8600.25です。受け付けるarchiveのSHA-256は `3894368ebce69f348d08e189c2f0818c49aa3b18ad01e06348743bf6a29af97a` です。パッケージ作成はゲームを起動しません。
