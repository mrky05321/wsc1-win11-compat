## ファイルを作らない状態取得

既存export `WSC1CompatGetStatus` の低位ビット（backend状態）は維持し、以下をORする。

| ビット | 意味 |
|---|---|
| `0x100` | IATフックの導入失敗・見送り |
| `0x200` | カーソル2か所の導入失敗・見送り |
| `0x400` | 保護復元の再試行失敗、または巻戻しの書込み許可取得失敗 |
| `0x800` | 命令キャッシュ同期失敗 |
| `0x1000` | Windowsフック登録失敗 |

保護復元の再試行失敗後に巻戻しが成功しても、検出した失敗ビットは保持する。元関数ポインタは常に保持する。任意の他フックとの全面的な共存、他スレッドとのコード書換えの原子性、OSが復旧を恒久的に拒否する場合の完全な巻戻しは保証しない。

実ゲーム再確認のため既存検証環境から739ファイルをハッシュ照合した新規複製を作り、その複製の専用DLLだけを候補版へ交換した。起動操作はUACで待機しており、実ゲームの画面・出音・入力は未確認。元ゲーム・DRM・既存セーブ・既存検証環境のDLL・配布Releaseは変更していない。候補DLLのSHA-256は `33abd1c2581288068bc32d95c1ef1079f2ccb7ef92e5af514026984ec1a651ff`。PRはドラフトのまま、イシューは実ゲームの再確認が残るためオープンを維持する。
