# v1.0.4

- 設計画面で左右キーによって兵装の向き・高さを変更したとき、配置前の兵装が左端へ飛ぶ問題を修正しました。ウィンドウの実際の原点から座標を求め、配置位置を保持します。
- 戦闘用カーソル画像の補正を、対象の戦闘描画だけに限定しました。
- 実行時パッチの事前検証と失敗時の復元、IAT差替えの競合検知、ウィンドウフックの失敗処理を強化しました（#1、#2、#4）。
- CD音源設定とWAVの形式・長さ、再生・シーク範囲を検証し、不正な音源では元のCD経路を使用します（#3）。
- ソースZIPに必要なヘッダー・回帰テスト・調査資料を追加し、展開後にビルドできるようにしました。

設計画面の修正は利用者が動作確認済みです。ファイル音源のBGMも改善の報告があります。ネイティブ回帰テストは、実ゲームの全場面を検証するものではありません。

既知のデスクトップ点滅と戦闘中の左下マップ黒化は未解決です。CDから直接再生した実際の出音、複数モニター、各種DPI、全ミッションは未検証です。コードパッチの他スレッドとの原子性は保証せず、実行中競合は再現されていません。詳細は [README](../README.md) と [調査記録](ISSUE_AUDIT_20261018.md) を参照してください。

配布ZIP内は4ファイル、導入するのは `ddraw.dll`、`dxwrapper.dll`、`dxwrapper.ini` の3ファイルです。v1.0.1～v1.0.3からは `ddraw.dll` だけを交換できます。既存のセーブ・表示設定・音源を残してください。

ゲーム本体、セーブ、音源は含みません。dxwrapperは従来と同じ未改変のv1.8.8600.25です。
